# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.x     | :white_check_mark: |
| 4.x     | :x:                |

## Reporting a Vulnerability

**DO NOT** report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in NEXUS Scanner Pro, please report it privately:

1.  **Email**: `kuashalraj9999@gmail.com`
2.  **Subject**: `[SECURITY] Vulnerability Report - NEXUS Scanner`

### Process
1.  You will receive an acknowledgment within 48 hours.
2.  We will investigate the issue and confirm its severity.
3.  We will fix the vulnerability and release a patch.
4.  We will publicly credit you (if you wish) in the release notes.

Thank you for practicing responsible disclosure and keeping the community safe! 🛡️
