```
1. Download the nexus-extension folder
2. Go to chrome://extensions/
3. Enable "Developer mode" (top right toggle)
4. Click "Load unpacked"
5. Select the nexus-extension folder
6. Pin extension → Click icon → Inject Scanner 🚀
```
