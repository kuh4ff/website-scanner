## 🎯 What is NEXUS Scanner Pro?

**NEXUS Scanner Pro** is an enterprise-grade web security assessment toolkit that combines:

- 🔍 **Advanced Security Scanner** - 200+ patterns for secrets, vulns, and misconfigurations
- 🤖 **Multi-AI Integration** - 6 providers with automatic failover
- 💻 **Terminal Commander** - Real-time browser ↔ server communication  
- 🧠 **Autonomous AI Brain** - Self-directed security analysis
- ⚡ **Auto-Exploitation** - One-click vulnerability testing

## 📦 Installation

### 📋 Prerequisites

```bash
# Required
Node.js 18+ 
npm or yarn

# Optional (for HTTPS tunneling)
cloudflared
```

### 🖥️ Terminal Commander

```bash
# Clone the repository
git clone https://github.com/kuh4ff/website-scanner.git

# Navigate to directory
cd website-scanner

# Install WebSocket dependency
npm install ws

# Start the terminal
node nexus-terminal.js

# With options
node nexus-terminal.js --port 8888 --ai-key YOUR_API_KEY
```

## 🚀 Quick Start

### Step 1: Start Terminal
```bash
node nexus-terminal.js
```

You'll see:
```
╔══════════════════════════════════════════════════════════════╗
║            🔥 NEXUS TERMINAL COMMANDER v5.0                  ║
║        Advanced Self-Healing Terminal with AI Integration    ║
╚══════════════════════════════════════════════════════════════╝

[AutoHealer] ✓ ws module found
[AutoHealer] ✓ Port 8080 is available
🚀 Server running on ws://192.168.x.x:8080
🔑 Auth Token: nexus_xxxxxx
```

### Step 2: Connect Extension
1. Click NEXUS extension icon
2. Go to **Terminal** tab
3. Enter: `ws://YOUR_IP:8080`
4. Enter Auth Token
5. Click **Connect** ✅

### Step 3: Inject & Scan
1. Go to target website
2. Click **💉 Inject**
3. Click **▶️ Start**
4. Watch findings appear! 🎯

| `secrets` | `sec` | Show extracted secrets |
| `endpoints` | `ep` | List discovered endpoints |
| `vulns` | `v` | Show vulnerabilities |
| `exploit <idx>` | `x` | Exploit specific finding |

| `ai <query>` | - | Ask AI about findings |
| `curl <idx>` | - | Generate curl command |
| `clear` | `cls` | Clear terminal |
| `broadcast <msg>` | - | Send to all browsers |

## 🔍 Scanner Features

### Detection Categories

<details>
<summary><b>🔐 Secrets & API Keys (50+ Patterns)</b></summary>

| Provider | Pattern |
|----------|---------|
| Google | `AIza[0-9A-Za-z-_]{35}` |
| AWS | `AKIA[0-9A-Z]{16}` |
| GitHub | `ghp_[a-zA-Z0-9]{36}` |
| Stripe | `sk_live_[0-9a-zA-Z]{24}` |
| OpenAI | `sk-[a-zA-Z0-9]{48}` |
| Slack | `xox[baprs]-[a-zA-Z0-9]+` |
| Firebase | `[a-zA-Z0-9_-]*:[a-zA-Z0-9_-]+@[a-z]+-[a-z]+-[a-z]+\.firebaseio\.com` |
| Twilio | `SK[a-f0-9]{32}` |
| SendGrid | `SG\.[a-zA-Z0-9_-]+\.[a-zA-Z0-9_-]+` |
| Mailgun | `key-[0-9a-zA-Z]{32}` |
| ... | And 40+ more! |

</details>

<details>
<summary><b>⚠️ Vulnerability Detection</b></summary>

| Type | Check |
|------|-------|
| **DOM XSS** | innerHTML, document.write, eval(), setTimeout |
| **Reflected XSS** | URL parameter reflection |
| **CORS** | Access-Control-Allow-Origin: * |
| **SSRF** | URL manipulation endpoints |
| **Open Redirect** | Location header manipulation |
| **Prototype Pollution** | __proto__, constructor.prototype |
| **GraphQL** | Introspection enabled, batching |
| **PostMessage** | Origin validation missing |
| **WebSocket** | Unencrypted, auth issues |
| **JSONP** | Callback injection |

</details>

<details>
<summary><b>📁 Discovery Features</b></summary>

- **Endpoints** - API routes, internal paths
- **Forms** - Input fields, hidden params
- **Scripts** - External JS, inline code
- **Cookies** - Session, auth tokens
- **Storage** - localStorage, sessionStorage
- **Headers** - Security headers analysis

</details>

## 🔧 Configuration

### Environment Variables

```bash
# AI Configuration
NEXUS_AI_KEY=your_api_key
NEXUS_AI_PROVIDER=groq

# Server Configuration
NEXUS_PORT=8080
NEXUS_AUTH_TOKEN=custom_token

# Features
NEXUS_AUTO_SYNC=true
NEXUS_AI_COLLAB=true
```

### Command Line Options

```bash
node nexus-terminal.js [options]

Options:
  --port <number>        Server port (default: 8080)
  --ai-key <key>         AI provider API key
  --no-cloudflare        Disable Cloudflare tunnel
  --no-auto-heal         Disable auto-healing
  --verbose              Verbose logging
```
