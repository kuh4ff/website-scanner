## 🛠️ How to Contribute

1.  **Fork the repo** to your own GitHub account.
2.  **Clone it** to your local machine:
    ```bash
    git clone https://github.com/YOUR_USERNAME/website-scanner.git
    ```
3.  **Create a branch** for your feature/fix:
    ```bash
    git checkout -b feature/amazing-new-scanner
    ```
4.  **Make your changes**.
5.  **Commit** your changes (please use clear commit messages):
    ```bash
    git commit -m "feat: add new SQL injection pattern"
    ```
6.  **Push** to your fork:
    ```bash
    git push origin feature/amazing-new-scanner
    ```
7.  **Open a Pull Request**!

## 🧪 Testing

Before submitting, please ensure:
- The code runs without errors.
- You have verified the feature locally.
- No secrets are committed (check your logs!).

## 🐛 Reporting Bugs

If you find a bug, please create an issue with:
1.  **Description** of the bug.
2.  **Steps to reproduce**.
3.  **Expected behavior**.
4.  **Screenshots** (if applicable).

## 💡 Feature Requests

Have an idea? Open an issue! We love hearing how to make NEXUS better.
